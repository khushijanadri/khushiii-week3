# Full Stack To-Do Application

## Project Overview
Developed a Full Stack To-Do Application by integrating a Week 2 REST API with a React frontend.

## Features
- User registration and login.
- JWT-based authentication.
- Protected routes.
- Create, read, update, and delete tasks.
- Mark tasks as completed or pending.
- Display total, completed, and pending tasks.
- Logout functionality.

## Technologies Used
- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- Axios
- React Router
- CSS

## How to Run
1. Install backend dependencies using `npm install`.
2. Configure MongoDB connection and JWT secret in `.env`.
3. Start backend using `npm run dev`.
4. Install frontend dependencies using `npm install`.
5. Start frontend using `npm run dev`.
6. Open `http://localhost:5173`.

## Conclusion
Successfully developed a full-stack To-Do application integrating a REST API with a React frontend, implementing authentication, CRUD operations, and client-side routing.
